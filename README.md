# Pós-Graduação em Data Analytics — Descomplica

Repositório dedicado à organização dos estudos, exercícios, notebooks, bases de dados e entregas desenvolvidos durante a Pós-Graduação em Data Analytics da Descomplica.

O objetivo é documentar a evolução do aprendizado, reunir exemplos práticos e manter os materiais acadêmicos organizados e versionados.

## Materiais de apoio

### Statistics Library in Python — Descomplica

Repositório de apoio disponibilizado pela Faculdade Descomplica, com scripts em Python organizados por aula (aulas 2 a 8). Material complementar para acompanhar os conteúdos de estatística e programação em Python.

- **Repositório:** [FaculdadeDescomplica/StatisticsLibraryinPython](https://github.com/FaculdadeDescomplica/StatisticsLibraryinPython)
- **Conteúdo identificado:** arquivos Python `descomplica_aula_2.py` até `descomplica_aula_8.py`.
- **Uso:** consulta e apoio aos estudos. Os notebooks e exercícios desenvolvidos neste repositório permanecem organizados separadamente.

## Tecnologias e ferramentas

- **Python** — linguagem utilizada nos estudos e análises.
- **Pandas** — manipulação, transformação e análise de dados.
- **NumPy** — operações numéricas e manipulação de arrays.
- **Regex** — identificação e manipulação de padrões em textos.
- **Jupyter Notebook / Google Colab** — desenvolvimento e execução dos notebooks.
- **Git e GitHub** — versionamento e organização dos materiais.

## Organização e atualização

- Os notebooks de aula ficam na pasta `notebooks/` e seguem uma numeração sequencial.

- O README é atualizado conforme novos materiais são adicionados ao repositório.
